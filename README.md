# 走进天津 · 像素剧情游戏

一个把真人短视频《走进天津》改写成**像素风剧情分支网页游戏**的项目：玩家坐地铁/打车/步行/骑行进天津，吃饭、中奖、听相声，全程用「伪文字冒险」的冷面笑点推进（假充值、假成就、幸运值），最后按收集结果进入三种结局。

纯静态站点：**零依赖、零框架、零构建**，HTML + CSS + 原生 JS + WebAudio，仓库克隆下来双击 `index.html` 就能玩。

## 怎么玩

```bash
# 直接打开
open index.html            # macOS
start index.html           # Windows

# 或用任意静态服务器（推荐，音频解锁更稳）
npx http-server -p 8124 -c-1
```

## 内容规模

| | |
|---|---|
| 章节 | 序章 → C1 出行 → C2 饭馆 → C3 中奖 → C4 相声茶馆 → C5 结局 |
| 剧情节点 | 92 个（含分支、随机、结算） |
| 成就 | 15 个（含隐藏成就「犹豫不决」「铁腿」「坐过站」） |
| 结局 | 3 个正式结局 + 1 个「余额不足」失败页 |
| 场景 | 17 张像素底图 + 7 段音频（4 段环境循环 + 3 个真实录音音效） |

**结局判定**（`js/story3.js` 的 `c5_route`，按优先级从上到下）：

1. **E3 隐藏结局「留在天津」** —— 成就 ≥ 7 且 C2 选过「打包」（塑料袋道具）
2. **E1 完美结局「天津，真好玩」** —— 幸运值 ≥ 8，或在茶馆 QTE 上台说过贯口
3. **E2 普通结局「下次再来」** —— 其余情况

剧本分支全图见 [剧情分支树.md](剧情分支树.md)（含每个梗的出处、条件与成就表）。

## 目录结构

```
index.html            页面骨架（画布 + 底图 + 对话框 + HUD）
css/style.css         像素渲染、对话框布局、移动端触控
js/
  engine.js           剧情引擎：9 种节点 + 幸运值/成就/计数器/悬停自动选择
  story.js            序章 + C1 出行（地铁报站链 / 打车 / 步行体力 / 骑行）
  story2.js           C2 饭馆（点菜、自由文本评价、打包/光盘）
  story3.js           C3 中奖刮刮乐 → C4 茶馆 → C5 三种结局
  art.js              像素底图加载与切换
  fx.js               逐帧动态层（摇晃、粒子、流光、震屏、地铁车窗卷轴）
  audio.js            WebAudio 环境音系统 + 音效
assets/bg/*.png       像素场景底图
assets/*.mp3          环境音循环与音效（部分为真实录音）
```

### 引擎支持的节点类型

`title` `narrate` `choice` `input`（关键词路由）`random` `route`（条件跳转）`qte`（限时点击）`scratch`（刮刮乐 canvas）`stamina`（连点体力）`summary`（章节结算）

数据驱动写法：每个节点是一个对象，`next`/`options`/`win`/`fail` 指向下一个节点 id；`effects` 里可以加幸运值、解锁成就、置 flag、累加点击计数（用于「嗑瓜子 10 次售罄」这类限制型选项）。环境音键默认取 `bg`，可用 `amb` 单独覆盖（画面与声音解耦）。

## 声音设计

没有任何旋律性 BGM——全部按场景定制：地铁车厢轰鸣、出租发动机、街道与餐馆使用**真实录音循环**，其余为 WebAudio 程序合成。音效一律由**剧情事件**触发（上菜、推门、嗑瓜子、中奖）而非按钮点击，且在声明的剧情边界处掐断（如进茶馆后中奖音乐立刻停止）。

## 部署方式

纯静态 + 相对路径，任何静态托管都可直接跑，不需要构建步骤：

- **GitHub Pages（推荐）**：仓库 Settings → Pages → Source 选 `Deploy from a branch`，分支 `main` / 目录 `/ (root)` 即可；或者加一个 Actions 工作流用 `actions/deploy-pages`。中文文件名只出现在文档里（`剧情分支树.md`），不影响站点资源，但如在意 URL 规范可改名为 `story-tree.md`。
- **Cloudflare Pages / Vercel / Netlify**：导入仓库，构建命令留空，输出目录 `/`。
- **任意对象存储 / 宝塔 / nginx**：把整个目录丢进去即可。

## 素材与二次开发注意

- 像素场景图由 AI 生成后统一做过「裁掉底部水印 + 等比放回」处理，比例保持 4:3（底图用 `object-fit: cover`，改比例会错位）。
- 新增章节：新建 `js/story4.js` 导出 `CHAPTER4`，在 `js/main.js` 里合并进 `STORY`，并在 `index.html` 追加 `<script>`；同时在 `js/art.js` 的 `IMG_NAMES` 与新场景的 `SCENES`（`js/audio.js`）里登记。
- 音频文件不能改名：`assets/` 下按字符串引用，无清单文件。
